# BiyoVes

Prepare Turkish biometric and vesikalık photos on your computer. [Project website](https://mehmetaytugyuruk.github.io/biyoves/)

## Quick start

[Download the ZIP](https://github.com/mehmetaytugyuruk/biyoves/archive/refs/heads/main.zip), extract it, and open a terminal in the extracted folder.

| Platform | Install first | Run |
| --- | --- | --- |
| Windows | [Python 3.13](https://www.python.org/downloads/windows/) | `py -3.13 start.py` |
| macOS / Linux | [uv](https://docs.astral.sh/uv/getting-started/installation/) | `uv run --no-project --python 3.13 start.py` |

The first launch installs dependencies and opens BiyoVes in your browser. Keep the terminal open while using the app. Models download when you process your first photo.
